1はじめに

このプライバシーポリシー（以下「本ポリシー」）は、iOS / Android 向けアプリ「RateLens」（以下「本アプリ」）での情報の扱いを説明するものです。本アプリは個人の開発者（以下「開発者」）が提供しています。

本アプリは、カメラや写真に写った値札の価格を読み取り、指定した通貨に換算して表示します。アカウント登録はありません。開発者はサーバーを運営しておらず、氏名・住所・電話番号の入力を求めることもありません。

2カメラと写真の扱い

  • カメラ映像と、あなたが選んだ写真の文字認識は、Google ML Kit の文字認識機能を使って端末の中だけで行います。映像や写真を開発者や第三者のサーバーへ送ることはありません。
  • 写真は、あなたが写真ライブラリから選んだ 1 枚だけを読み込みます。写真ライブラリ全体を読み取ることはありません。
  • カメラと写真へのアクセスは、OS の許可画面であなたが許可したときだけ使います。許可はいつでも端末の設定で取り消せます。
  • Google の説明によると、ML Kit は機能の性能や利用状況についての指標（端末の情報など）を Google に送ることがあります。この指標に画像や読み取った文字は含まれません。詳しくは ML Kit の利用規約 をご覧ください。

3端末の中にだけ保存する情報

  • 換算の履歴（撮影または選んだ写真の複製、読み取った金額、通貨、換算に使ったレートの日付）。最大 200 件まで保存し、古いものから自動で消します。
  • 最後に取得した為替レート（通信できないときに使うため）
  • 選んだ通貨などの設定、広告の表示間隔を決めるための日時

これらは端末の中のアプリ専用の領域にだけ保存し、開発者や第三者へ送ることはありません。履歴は 1 件ずつアプリ内で削除できます。本アプリを削除すると、これらの情報はすべて消えます。開発者はこれらの情報を持っていないため、復元や削除の代行はできません。

4為替レートの取得

換算に使う為替レートを取得するため、本アプリは次の公開サービスに通信します。1 つ目に接続できないときに 2 つ目を使います。

  • Frankfurter（api.frankfurter.dev） サービスの説明
  • currency-api（latest.currency-api.pages.dev） サービスの説明

送るのは「どの通貨のレートが欲しいか」という要求だけです。写真、金額、履歴、個人を特定できる情報は送りません。ただし、インターネット通信の仕組み上、あなたの IP アドレスやアプリの通信情報が各サービスの運営者に届きます。その扱いは各サービスの方針によります。

5広告（Google AdMob）

本アプリは Google AdMob（Google Mobile Ads SDK）を使い、バナー広告、インタースティシャル広告（全画面の広告）、リワード広告（見ると履歴をしばらく全部見られる広告）を表示します。広告の配信のため、次の情報が端末から Google に送られ、Google が扱います。

  • 広告 ID などの識別子（Android の広告 ID、App Set ID など）
  • IP アドレス（おおよその位置の推定に使われることがあります）
  • 端末とアプリの情報（機種、OS とそのバージョン、言語、アプリのバージョンなど）
  • 広告の表示、タップ、動画の視聴などの操作
  • SDK の不具合や性能についての診断情報

本アプリは iOS の App Tracking Transparency（ATT）によるトラッキングの許可を求めていません。そのため、iOS では広告識別子（IDFA）を使いません。

Google による情報の使い方は、Google のサービスを使用するサイトやアプリから収集した情報の Google による使用、Google の広告について、Google プライバシーポリシー をご覧ください。

6広告の同意（EEA・英国など）

欧州経済領域（EEA）、英国、スイスなど、法律で同意が必要な地域では、本アプリは Google の User Messaging Platform（UMP SDK）を使い、広告のための情報の利用について起動時に同意を求めます。これは Google の EU ユーザーの同意ポリシー に沿ったものです。

  • 同意しなくても本アプリは使えます。その場合、Google はパーソナライズしない広告や、制限した広告を表示します。
  • 同意の状態は端末に保存されます。本アプリを削除して入れ直すと、もう一度同意を求めます。
  • EEA などにお住まいの方は、一般データ保護規則（GDPR）に基づき、アクセス、訂正、削除、処理の制限、異議、同意の撤回などの権利を持ちます。開発者は広告のデータを持っていないため、Google が持つデータについては Google プライバシーポリシー の手続きもご利用ください。

Android では、端末の設定（多くの機種で「設定」→「Google」→「広告」）で広告 ID をリセットまたは削除できます。メニューの名前は機種によって異なります。

7有料プラン（RateLens Pro）の購入

本アプリは今後、有料プラン「RateLens Pro」（買い切り、または年額の自動更新サブスクリプション）を提供する予定です。提供を始めた場合、決済は Apple（App Store）または Google（Google Play）が行います。開発者がクレジットカードなどの支払い情報を受け取ることはありません。購入の状態を確かめるため、ストアの購入記録を使います。

8お問い合わせのときに受け取る情報

あなたがメールで問い合わせたときは、返信のために、メールアドレス、お名前（書かれていた場合）、本文を使います。返信に必要な期間だけ保管し、その後削除します。

9集めない情報

  • 氏名、住所、電話番号（問い合わせのメールに書かれた場合を除く）
  • 連絡先、マイク、正確な位置情報（GPS）
  • アクセス解析やクラッシュ解析のツールによるデータ（現在は使っていません。使う場合は本ポリシーを更新します）

開発者は、個人情報をお金と引き換えに販売しません。

10子どもの情報

本アプリは 13 歳未満の子どもを対象にしていません。13 歳未満の子どもの個人情報を、開発者が知りながら集めることはありません。

11海外での処理

Google などのサービスを使うため、情報は米国など日本以外の国のデータセンターで処理されることがあります。

12本ポリシーの変更

法律の変更や機能の追加（有料プランの提供開始など）に合わせて、本ポリシーを変更することがあります。変更したときは、このページの「最終更新日」を改めます。
