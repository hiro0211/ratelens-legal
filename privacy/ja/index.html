1はじめに

このプライバシーポリシー（以下「本ポリシー」）では、アプリ「RateLenz」（以下「本アプリ」）が情報をどう扱うかを説明します。本アプリは DefactoTech（有村大旭、Hiroaki Arimura。以下「開発者」）が提供しています。

本アプリは、カメラに写った値札の価格を読み取り、あなたが選んだ通貨に換算して表示します。アカウント登録とログインはありません。開発者は自分のサーバーを運営しておらず、氏名・住所・電話番号の入力も求めません。

本アプリは、広告の配信に Google AdMob を、有料プランの購入の管理に RevenueCat を、利用状況の分析に Google の Firebase Analytics を使います。これらのサービスに送られる情報は、5〜8 章で説明します。

2カメラと写真の扱い

  • 値札の文字は端末の中で読み取ります。iOS では Apple の Vision フレームワークを使います。Android 版では、Google ML Kit の文字認識を端末の中で使います。
  • カメラの映像、写真、読み取った文字と金額を、開発者や第三者のサーバーへ送ることはありません。ML Kit を使う Android 版でも、画像は端末の中で読むだけで、Google へは送りません。
  • ただし、Android 版の ML Kit 自体は、診断と利用状況の分析のために情報を Google に送ります。送るのは、端末の情報（メーカー、機種、OS のバージョン）とアプリの情報（パッケージ名とバージョン）です。ほかに、インストールごとの識別子、性能の指標、設定、エラーコードなども送ります。Google の説明では、この情報は HTTPS で暗号化して送られ、第三者には渡されません。詳しくは ML Kit のデータの開示 をご覧ください。
  • 写真を選んで換算するときは、あなたが選んだ 1 枚だけを読み込みます。ライブラリ全体は読み取りません。
  • iOS では、写真ライブラリから 1 枚を選びます。カメラと写真は、OS の許可画面であなたが許可したときだけ使います。
  • Android では、OS の写真選択ツールを使います。本アプリに渡されるのは、あなたが選んだ 1 枚だけです。Android では写真の権限を求めません。カメラは、OS の許可画面であなたが許可したときだけ使います。
  • カメラなどの許可は、端末の設定でいつでも取り消せます。

3端末の中にだけ保存する情報

  • 換算の履歴。撮った写真の複製、読み取った金額、通貨、換算に使ったレートの日付を保存します。最大 200 件まで残し、古いものから自動で消します。
  • 最後に取得した為替レート。通信できないときの換算に使います。
  • 選んだ通貨などの設定、その日にかざした回数、広告の表示間隔を決めるための日時。
  • 初めて開いた日時と、有料プランを購入しているかどうかの控え。

これらは端末の中のアプリ専用の領域にだけ保存し、開発者や第三者へは送りません。履歴は 1 件ずつアプリの中で削除できます。

バックアップと削除の扱いは、Android と iPhone で異なります。

  • Android: 本アプリは、これらの情報を Google のバックアップの対象から外しています。新しい端末へデータを移すときも、引き継ぎません。本アプリを削除すると、すべて消えます。
  • iPhone: 履歴と設定は、iCloud やパソコンへの端末のバックアップに含まれることがあります。iCloud バックアップは Apple が保存し、開発者は見られません。バックアップに残したくないときは、端末の設定で本アプリのバックアップを止めるか、バックアップを削除してください。
  • iPhone: 次の情報は、iPhone のキーチェーンに保存します。その日にかざした回数、広告の表示間隔の日時、初めて開いた日時、購入の状態の控えです。削除と再インストールで回数が戻らないようにするためです。キーチェーンの情報は、本アプリを削除しても端末に残り、バックアップにも含まれることがあります。

開発者は、この章で挙げた端末の中の情報を持っていません。そのため、その復元や削除の代行はできません。購入の情報（7 章）の削除は、13 章 をご覧ください。

4為替レートの取得

本アプリは、換算に使う為替レートを次の公開サービスから読み込みます。1 つ目に接続できないときだけ 2 つ目を使います。

  • Frankfurter（api.frankfurter.dev） サービスの説明
  • currency-api（latest.currency-api.pages.dev） サービスの説明

本アプリが送るのは「どの通貨のレートが欲しいか」という要求だけです。写真、金額、履歴、あなたを特定できる情報は送りません。ただし、インターネット通信の仕組み上、あなたの IP アドレスなどの通信情報は各サービスの運営者に届きます。運営者はその情報を各自の方針で扱います。

5広告（Google AdMob）とトラッキング

本アプリは Google AdMob（Google Mobile Ads SDK）を使い、2 種類の広告を表示します。1 つはインタースティシャル広告（全画面の広告）です。もう 1 つはリワード広告で、あなたが選んで見ると、その日にかざせる回数が増えます。広告を配信するため、端末は次の情報を Google に送り、Google がその情報を扱います。

  • 広告の識別子。iOS では、あなたがトラッキングを許可したときだけ IDFA（広告識別子）が送られます。Android では広告 ID や App Set ID が送られます。端末の設定で広告 ID を削除すると、本アプリから広告 ID は送られなくなります。削除とリセットの方法は 6 章の最後に書いています。
  • IP アドレス。Google はこれを使っておおよその位置を推定することがあります。Google はこの情報を、広告の配信、分析、不正の防止に使います。
  • 広告のデータと操作。広告の表示、タップ、動画の視聴などです。
  • 端末とアプリの情報。機種、OS とそのバージョン、言語、アプリのバージョンなどです。
  • 診断のデータ。SDK の性能、クラッシュ、不具合についての情報です。

iOS では、本アプリは App Tracking Transparency（ATT）の画面でトラッキングの許可を求めます。許可すると、Google は IDFA を使い、ほかの会社のアプリやサイトでの行動と合わせてあなたに合った広告を表示することがあります。許可しなくても本アプリはすべて使えます。その場合、IDFA は送られません。許可はあとから端末の「設定」→「プライバシーとセキュリティ」→「トラッキング」で変えられます。

有料プランを購入している間は、広告を表示しません。

不適切な広告を見つけたときは、本アプリの「設定」→「不適切な広告を報告」から、または下記のメールアドレスでお知らせください。

Google による情報の使い方は、Google のサービスを使用するサイトやアプリから収集した情報の Google による使用、Google の広告について、Google プライバシーポリシー をご覧ください。

6広告の同意（EEA・英国など）

欧州経済領域（EEA）、英国、スイスなど、法律で同意が必要な地域では、本アプリは Google の User Messaging Platform（UMP SDK）を使います。最初に使うときに、広告のための情報の利用について同意を求めます。これは Google の EU ユーザーの同意ポリシー に沿ったものです。

  • 同意しなくても本アプリは使えます。その場合、Google はパーソナライズしない広告や、制限した広告を表示します。
  • 同意しなかったときは、本アプリは ATT の画面を出さず、IDFA も送りません。
  • 同意の状態は端末に保存されます。対象の地域では、アプリの設定画面から同意の内容を変えられます。
  • EEA などにお住まいの方は、一般データ保護規則（GDPR）に基づき、アクセス、訂正、削除、処理の制限、異議、同意の撤回などの権利を持ちます。開発者は広告のデータを持っていません。Google が持つデータについては、Google プライバシーポリシー の手続きもご利用ください。

Android では、端末の設定で広告 ID をリセットまたは削除できます。多くの機種では「設定」→「Google」→「広告」にあります。メニューの名前は機種によって異なります。

  • リセットすると、新しい広告 ID に変わります。これまでの ID とは結び付かなくなります。
  • 削除すると、広告 ID はゼロだけの値に置き換わります。本アプリからも、広告 ID は送られなくなります。
  • Android の広告には、Google の Privacy Sandbox（トピックなど）が使われることがあります。端末の設定の「広告のプライバシー」で止められます。

7有料プラン（RateLenz Premium）と RevenueCat

本アプリには有料プラン「RateLenz Premium」があります。決済は Apple（App Store）または Google（Google Play）が行います。開発者は、クレジットカードなどの支払い情報を受け取りません。

購入の状態を確かめるため、本アプリは RevenueCat, Inc. の RevenueCat SDK を使います。RevenueCat には次の情報が送られます。

  • 購入の履歴。購入したプラン、購入と更新の日時、ストアの取引の情報です。
  • 匿名の App User ID。本アプリが端末ごとに自動で作る番号で、名前やメールアドレスとは結び付きません。
  • 端末とアプリの情報。OS のバージョン、アプリのバージョン、国や地域、言語などです。

開発者は、これらの情報を購入の確認、購入の復元、売上の集計に使います。広告やトラッキングには使いません。RevenueCat による情報の扱いは RevenueCat のプライバシーポリシー をご覧ください。

購入の情報の保存期間は次のとおりです。

  • 開発者は、購入の情報を期限を決めずに RevenueCat に残します。購入の復元と、サブスクリプションの状態の確認に使うためです。あなたから削除の依頼を受けたときは、13 章 の手順で削除します。
  • 開発者が削除すると、RevenueCat の案内では、その利用者の購入の履歴を含むすべてのデータが消されます。削除の処理は RevenueCat の中で順番に進みます。
  • RevenueCat がバックアップなどにいつまで情報を残すかは、RevenueCat の方針に従います。RevenueCat のプライバシーポリシーには、法令の義務を守るのに必要な範囲で保存すると書かれています。

8利用状況の分析（Firebase Analytics）

開発者は、本アプリを改善するため、Google の Firebase Analytics（Google アナリティクス for Firebase）を使います。どの機能がどれだけ使われているか、どこで使うのをやめているか、続けて使われているかを調べるためです。本アプリから Google に次の情報が送られます。

  • アプリインスタンス ID。Firebase がインストールごとに自動で作る番号です。名前やメールアドレスとは結び付きません。開発者は、ユーザー ID を設定しません。
  • アプリの中での操作。開いた画面、オンボーディングの進み具合、かざした回数と読み取れた値札の数、手入力、通貨の切り替え、履歴と設定の操作、広告と課金画面の操作と結果などです。回数や時間は「4 回以上」「5〜15 秒」のような区分で送ります。
  • アプリの状態。選んだ通貨の組み合わせ、表示の明暗、有料プランの種類、トラッキングと広告の同意の結果などです。
  • 端末とアプリの情報。機種、OS とそのバージョン、言語、アプリのバージョン、初めて開いた日時、セッションの長さなどです。
  • おおよその地域。Google が IP アドレスから国や地域を推定します。正確な位置情報（GPS）は使いません。
  • 購入のイベント。有料プランの購入の種類と金額を、Google が自動で記録します。
  • 広告の識別子。iOS では、あなたがトラッキングを許可したときだけ、IDFA が送られることがあります。Android では広告 ID が送られることがあります。端末の設定で広告 ID を削除すると送られなくなります（6 章）。

カメラの映像、写真、読み取った文字と金額、換算の履歴の中身は送りません。

開発者は、この情報を本アプリの改善と利用状況の集計だけに使います。広告のパーソナライズやトラッキングには使いません。Google シグナルと Google 広告とのリンクは使っていません。開発者は、この情報を Google の BigQuery（Google Cloud のデータベース）に書き出して集計します。BigQuery のデータは開発者だけが見られ、第三者には渡しません。

同意の扱いは次のとおりです。

  • EEA・英国・スイスなど同意が必要な地域では、6 章の同意の画面で選んだ内容に従います。同意しなかったときは、Google は識別子を保存せず、個人に結び付かない集計の推定にだけ情報を使います。同意の画面が出る前は、本アプリは情報を送りません。
  • 同意の内容は、アプリの設定画面の「プライバシーの選択」から変えられます。
  • iOS でトラッキングを許可しなかったときは、IDFA は送られません。

保存期間は次のとおりです。Google アナリティクスの画面の中の詳細なデータは、Google アナリティクスの保持期間の設定に従って消えます。BigQuery に書き出したデータは、続けて使われているかを長く比べるため、期限を決めずに保存します。データは名前やメールアドレスと結び付いていないため、開発者は特定の人のデータを見つけられません。そのため、削除の扱いは 13 章 をご覧ください。

Google による情報の扱いは、Google アナリティクスのデータの保護、Firebase のプライバシーとセキュリティ、Google プライバシーポリシー をご覧ください。

9お問い合わせのときに受け取る情報

あなたがメールで問い合わせたときは、返信のために、メールアドレス、お名前（書かれていた場合）、本文を使います。返信に必要な期間だけ保管し、その後削除します。

10集めない情報

  • 氏名、住所、電話番号（問い合わせのメールに書かれた場合を除く）
  • 連絡先、マイク、正確な位置情報（GPS）
  • カメラの映像、写真、読み取った文字と金額、換算の履歴
  • クラッシュ解析のツールによるデータ（現在は使っていません。使う場合は本ポリシーを更新します）。利用状況の分析は 8 章の Firebase Analytics だけを使います。

開発者は、個人情報をお金と引き換えに販売しません。

11子どもの情報

本アプリは 13 歳未満の子どもを対象にしていません。開発者は、13 歳未満の子どもの個人情報を知りながら集めることはありません。

12通信の暗号化と海外での処理

本アプリの通信は、すべて HTTPS（TLS）で暗号化します。為替レートのサービス、Google（AdMob、ML Kit、Firebase Analytics）、RevenueCat との通信が対象です。

本アプリは Google や RevenueCat のサービスを使います。そのため、情報は米国など日本以外の国のデータセンターで処理されることがあります。

13データの削除

本アプリにアカウントはありません。消したい情報の種類ごとに、次の方法で削除できます。

  • 端末の中の情報（換算の履歴、為替レート、設定）。履歴は、アプリの中で 1 件ずつ削除できます。Android では、本アプリを端末から削除するとすべて消えます。iPhone では、キーチェーンに保存した回数などが端末に残ることがあります。iPhone のバックアップに残っている場合は、バックアップも削除してください（3 章）。
  • 購入の情報（RevenueCat）。下記のメールアドレスに削除を依頼してください。開発者が RevenueCat に記録された購入の情報を削除します。
  • 広告の情報（Google）。開発者は広告のデータを持っていません。広告 ID は、端末の設定で削除またはリセットできます（6 章）。Google が持つデータは、Google の手続きで削除を依頼できます。
  • 利用状況の分析の情報（Firebase Analytics）。この情報は名前やメールアドレスと結び付いていないため、開発者は特定の人の情報を見つけられません。本アプリを削除すると、端末のアプリインスタンス ID が消え、それ以降の情報とは結び付かなくなります。EEA などでは、設定画面の「プライバシーの選択」で同意を取り消せます（8 章）。

購入の情報の削除を依頼するときは、あなたの購入を見つけるため、次のどちらかをメールに書いてください。

  • Android: Google Play の注文番号（「GPA.」で始まる番号）。Google Play から届く購入の確認メールに書かれています。
  • iPhone: App Store のレシートにある注文 ID（Order ID）。Apple から届く領収書のメールに書かれています。

開発者は、依頼を受け取ってから 14 日以内を目安に返信します。購入の情報を削除しても、サブスクリプションは解約されません。解約は、各ストアの手続きで行ってください（利用規約 5 章）。削除のあとに「購入を復元」を使うと、購入の情報が RevenueCat に改めて記録されます。
