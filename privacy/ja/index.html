1はじめに

このプライバシーポリシー（以下「本ポリシー」）では、アプリ「RateLenz」（以下「本アプリ」）が情報をどう扱うかを説明します。本アプリは個人の開発者（以下「開発者」）が提供しています。

本アプリは、カメラに写った値札の価格を読み取り、あなたが選んだ通貨に換算して表示します。アカウント登録とログインはありません。開発者は自分のサーバーを運営しておらず、氏名・住所・電話番号の入力も求めません。

本アプリは、広告の配信に Google AdMob を、有料プランの購入の管理に RevenueCat を使います。これらのサービスに送られる情報は、5〜7 章で説明します。

2カメラと写真の扱い

  • 値札の文字は端末の中で読み取ります。iOS では Apple の Vision フレームワークを使います。Android 版では、Google ML Kit の文字認識を端末の中で使います。
  • カメラの映像、写真、読み取った文字と金額を、開発者や第三者のサーバーへ送ることはありません。
  • 写真を選んで換算するときは、あなたが写真ライブラリから選んだ 1 枚だけを読み込みます。ライブラリ全体は読み取りません。
  • カメラと写真は、OS の許可画面であなたが許可したときだけ使います。許可は端末の設定でいつでも取り消せます。

3端末の中にだけ保存する情報

  • 換算の履歴。撮った写真の複製、読み取った金額、通貨、換算に使ったレートの日付を保存します。最大 200 件まで残し、古いものから自動で消します。
  • 最後に取得した為替レート。通信できないときの換算に使います。
  • 選んだ通貨などの設定、その日にかざした回数、広告の表示間隔を決めるための日時。

これらは端末の中のアプリ専用の領域にだけ保存し、開発者や第三者へは送りません。履歴は 1 件ずつアプリの中で削除できます。本アプリを削除すると、これらの情報はすべて消えます。開発者はこれらの情報を持っていないため、復元や削除の代行はできません。

4為替レートの取得

本アプリは、換算に使う為替レートを次の公開サービスから読み込みます。1 つ目に接続できないときだけ 2 つ目を使います。

  • Frankfurter（api.frankfurter.dev） サービスの説明
  • currency-api（latest.currency-api.pages.dev） サービスの説明

本アプリが送るのは「どの通貨のレートが欲しいか」という要求だけです。写真、金額、履歴、あなたを特定できる情報は送りません。ただし、インターネット通信の仕組み上、あなたの IP アドレスなどの通信情報は各サービスの運営者に届きます。運営者はその情報を各自の方針で扱います。

5広告（Google AdMob）とトラッキング

本アプリは Google AdMob（Google Mobile Ads SDK）を使い、2 種類の広告を表示します。1 つはインタースティシャル広告（全画面の広告）です。もう 1 つはリワード広告で、あなたが選んで見ると、その日にかざせる回数が増えます。広告を配信するため、端末は次の情報を Google に送り、Google がその情報を扱います。

  • 広告の識別子。iOS では、あなたがトラッキングを許可したときだけ IDFA（広告識別子）が送られます。Android では広告 ID や App Set ID が送られます。
  • IP アドレス。Google はこれを使っておおよその位置を推定することがあります。
  • 広告のデータと操作。広告の表示、タップ、動画の視聴などです。
  • 端末とアプリの情報。機種、OS とそのバージョン、言語、アプリのバージョンなどです。
  • 診断のデータ。SDK の性能、クラッシュ、不具合についての情報です。

iOS では、本アプリは App Tracking Transparency（ATT）の画面でトラッキングの許可を求めます。許可すると、Google は IDFA を使い、ほかの会社のアプリやサイトでの行動と合わせてあなたに合った広告を表示することがあります。許可しなくても本アプリはすべて使えます。その場合、IDFA は送られません。許可はあとから端末の「設定」→「プライバシーとセキュリティ」→「トラッキング」で変えられます。

有料プランを購入している間は、広告を表示しません。

Google による情報の使い方は、Google のサービスを使用するサイトやアプリから収集した情報の Google による使用、Google の広告について、Google プライバシーポリシー をご覧ください。

6広告の同意（EEA・英国など）

欧州経済領域（EEA）、英国、スイスなど、法律で同意が必要な地域では、本アプリは Google の User Messaging Platform（UMP SDK）を使います。最初に使うときに、広告のための情報の利用について同意を求めます。これは Google の EU ユーザーの同意ポリシー に沿ったものです。

  • 同意しなくても本アプリは使えます。その場合、Google はパーソナライズしない広告や、制限した広告を表示します。
  • 同意の状態は端末に保存されます。対象の地域では、アプリの設定画面から同意の内容を変えられます。
  • EEA などにお住まいの方は、一般データ保護規則（GDPR）に基づき、アクセス、訂正、削除、処理の制限、異議、同意の撤回などの権利を持ちます。開発者は広告のデータを持っていません。Google が持つデータについては、Google プライバシーポリシー の手続きもご利用ください。

Android では、端末の設定で広告 ID をリセットまたは削除できます。多くの機種では「設定」→「Google」→「広告」にあります。メニューの名前は機種によって異なります。

7有料プラン（RateLenz Premium）と RevenueCat

本アプリには有料プラン「RateLenz Premium」があります。決済は Apple（App Store）または Google（Google Play）が行います。開発者は、クレジットカードなどの支払い情報を受け取りません。

購入の状態を確かめるため、本アプリは RevenueCat, Inc. の RevenueCat SDK を使います。RevenueCat には次の情報が送られます。

  • 購入の履歴。購入したプラン、購入と更新の日時、ストアの取引の情報です。
  • 匿名の App User ID。本アプリが端末ごとに自動で作る番号で、名前やメールアドレスとは結び付きません。
  • 端末とアプリの情報。OS のバージョン、アプリのバージョン、国や地域、言語などです。

開発者は、これらの情報を購入の確認、購入の復元、売上の集計に使います。広告やトラッキングには使いません。RevenueCat による情報の扱いは RevenueCat のプライバシーポリシー をご覧ください。

8お問い合わせのときに受け取る情報

あなたがメールで問い合わせたときは、返信のために、メールアドレス、お名前（書かれていた場合）、本文を使います。返信に必要な期間だけ保管し、その後削除します。

9集めない情報

  • 氏名、住所、電話番号（問い合わせのメールに書かれた場合を除く）
  • 連絡先、マイク、正確な位置情報（GPS）
  • カメラの映像、写真、読み取った文字と金額、換算の履歴
  • 開発者が独自に入れたアクセス解析やクラッシュ解析のツールによるデータ（現在は使っていません。使う場合は本ポリシーを更新します）

開発者は、個人情報をお金と引き換えに販売しません。

10子どもの情報

本アプリは 13 歳未満の子どもを対象にしていません。開発者は、13 歳未満の子どもの個人情報を知りながら集めることはありません。

11海外での処理

本アプリは Google や RevenueCat のサービスを使います。そのため、情報は米国など日本以外の国のデータセンターで処理されることがあります。

12本ポリシーの変更

開発者は、法律の変更や機能の追加に合わせて本ポリシーを変更することがあります。変更したときは、このページの「最終更新日」を改めます。
